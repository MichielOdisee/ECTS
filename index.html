📊 ELOICT Linked Data

Dit is de officiële Linked Data dataset van de opleiding ELO ICT (Odisee). De dataset bevat alle vakken, docenten, studiepunten, skills en prerequisites in RDF/Turtle.

🔗 Namespace

https://michielodisee.github.io/eloict-linked-data#

📥 Download dataset

eloict.ttl

SPARQL Voorbeeld

PREFIX eloict: <https://michielodisee.github.io/eloict-linked-data#>
PREFIX rdfs: 

SELECT ?vak ?naam ?credits WHERE {
  ?vak a eloict:CourseUnit ;
       rdfs:label ?naam ;
       eloict:hasCredits ?credits .
} ORDER BY ?naam
