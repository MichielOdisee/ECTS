ELOICT – Linked Data Dataset

Open RDF-/Linked Data dataset van de opleiding ELO ICT – Odisee Hogeschool. De dataset bevat vakken, docenten, studiepunten, prerequisites en skills in Turtle (.ttl).

🧠 Voorbeeld SPARQL Query

PREFIX eloict: 
PREFIX rdfs:   

SELECT 
    (STRAFTER(STR(?vak),"#") AS ?vakID)
    ?naam
    ?code
    (CONCAT(STR(?credits)," SP") AS ?studiepunten)
    (STRAFTER(STR(?sem),"#") AS ?semester)
    (STRAFTER(STR(?ph),"#") AS ?fase)
    (GROUP_CONCAT(DISTINCT ?lectNaam; SEPARATOR=", ") AS ?docenten)
    ?coordinator
WHERE {
    ?vak a eloict:CourseUnit ;
         rdfs:label ?naam ;
         eloict:courseCode ?code ;
         eloict:hasCredits ?credits ;
         eloict:belongsToSemester ?sem ;
         eloict:belongsToPhase ?ph .

    OPTIONAL{
        ?vak eloict:hasLecturer ?lect .
        ?lect rdfs:label ?lectNaam .
    }
    OPTIONAL{
        ?vak eloict:hasCoordinator ?c .
        ?c rdfs:label ?coordinator .
    }
}
GROUP BY ?vak ?naam ?code ?credits ?sem ?ph ?coordinator
ORDER BY ?fase ?semester ?naam

💻 Dataset lokaal gebruiken

1. Download eloict-curriculum-latest.ttl hierboven
2. Open met een tool naar keuze:

  • 🔸 Apache Jena Fuseki → localhost SPARQL endpoint draaien
  • 🔸 GraphDB / Stardog / OntoRefine voor visuele graph weergave
  • 🔸 VSCode + Turtle plugin om data te bekijken

Snel lokaal hosten in Fuseki:

1. Start Fuseki → http://localhost:3030
2. Create Dataset → Upload eloict-curriculum-latest.ttl
3. Open SPARQL tab → plak de query hierboven
4. Resultaten verschijnen direct
