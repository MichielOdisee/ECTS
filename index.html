ELOICT – Linked Data Dataset

Dit is een open RDF-dataset van de opleiding ELO ICT (Odisee Hogeschool). De dataset bevat alle vakken, docenten, studiepunten, skills en prerequisites in Turtle (.ttl) formaat.

🧠 Voorbeeld SPARQL Query

PREFIX eloict: 
PREFIX rdfs: 

SELECT 
    (STRAFTER(STR(?vak),"#") AS ?vakID)
    ?naam
    ?code
    (CONCAT(STR(?credits)," SP") AS ?studiepunten)
    (STRAFTER(STR(?sem),"#") AS ?semester)
    (STRAFTER(STR(?ph),"#") AS ?phase)
    (GROUP_CONCAT(DISTINCT ?lectNaam; SEPARATOR=", ") AS ?docenten)
    ?coordinatorNaam
WHERE {
    ?vak a eloict:CourseUnit ;
         rdfs:label ?naam ;
         eloict:courseCode ?code ;
         eloict:hasCredits ?credits ;
         eloict:belongsToSemester ?sem ;
         eloict:belongsToPhase ?ph .

    OPTIONAL{
        ?vak eloict:hasLecturer ?lect .
        ?lect rdfs:label ?lectNaam .
    }

    OPTIONAL{
        ?vak eloict:hasCoordinator ?coord .
        ?coord rdfs:label ?coordinatorNaam .
    }
}
GROUP BY ?vak ?naam ?code ?credits ?sem ?ph ?coordinatorNaam
ORDER BY ?phase ?semester ?naam
