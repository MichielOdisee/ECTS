ELO ICT – Linked Data Dataset

RDF-dataset van de opleiding ELO ICT (Odisee Hogeschool)

Projectcontext: deze linked-data set is uitgewerkt in het kader van het vak POP (Persoonlijk OntwikkelingsProject) binnen de opleiding ELO ICT. De data is samengesteld door een student en is geen officieel Odisee-product, maar verwijst wel naar officiële cursusfiches via rdfs:seeAlso.

De dataset beschrijft alle vakken, docenten, studiepunten, skills en relaties (zoals prerequisites en specialisaties) in Turtle (.ttl)-formaat. De URI-ruimte wordt genormaliseerd onder http://odisee.be/eloict#, zodat de data eenvoudig te hergebruiken is in SPARQL-endpoints en knowledge graphs.

🧠 Voorbeeld SPARQL-query

Onderstaande query geeft een professioneel overzicht van alle eloict:CourseUnit-vakken met code, studiepunten, semester, fase, docenten en coördinator. 

PREFIX eloict: <http://odisee.be/eloict#>
PREFIX rdfs:   <http://www.w3.org/2000/01/rdf-schema#>

SELECT 
    (STRAFTER(STR(?vak), "#") AS ?vakID)
    ?naam
    ?code
    (CONCAT(STR(?credits), " SP") AS ?studiepunten)
    (STRAFTER(STR(?sem), "#") AS ?semester)
    (STRAFTER(STR(?ph),  "#") AS ?fase)
    (GROUP_CONCAT(DISTINCT ?lectNaam; SEPARATOR=", ") AS ?docenten)
    ?coordinatorNaam
WHERE {
    ?vak a eloict:CourseUnit ;
         rdfs:label            ?naam ;
         eloict:courseCode     ?code ;
         eloict:hasCredits     ?credits ;
         eloict:belongsToSemester ?sem ;
         eloict:belongsToPhase    ?ph .

    OPTIONAL {
        ?vak  eloict:hasLecturer  ?lect .
        ?lect rdfs:label          ?lectNaam .
    }

    OPTIONAL {
        ?vak   eloict:hasCoordinator ?coord .
        ?coord rdfs:label            ?coordinatorNaam .
    }
}
GROUP BY ?vak ?naam ?code ?credits ?sem ?ph ?coordinatorNaam
ORDER BY ?fase ?semester ?naam
